Web Development Fundamentals

A beginner-friendly course designed to help you create modern, responsive websites using HTML, CSS & JavaScript.

About This Course

This practical course takes you from your first HTML tag to building a complete portfolio website. You will learn through short lessons, hands-on activities & guided projects.

Learning Outcomes

  • Create structured web pages with HTML5.
  • Style pages using CSS selectors, colours & layouts.
  • Build responsive pages for mobile, tablet & desktop.
  • Use JavaScript for simple interactive features.
  • Create forms, tables, navigation menus & media sections.
  • Publish a beginner portfolio project online.

Course Note

Important: No coding experience is required. Bring your curiosity, practise regularly & ask questions.

Recommended study time: 4–6 hours every week. Course fee: ₹2,999 only.

“Learning to code is not about memorising syntax; it is about learning how to solve problems.”

Course Curriculum

Learning Roadmap

  1. Understand the internet, browsers and web development tools.
  2. Learn HTML structure, headings, links, images and lists.
  3. Use CSS to style colours, fonts, spacing and layouts.
  4. Create responsive webpages using media queries.
  5. Learn JavaScript basics and user interaction.
  6. Build, test & present your final portfolio project.
